# Synapse Swarm Engine

A lightweight multi-agent orchestration pattern that enables a single master model to dynamically morph into specialized expert personas (such as a Python Architect or Skeptical Critic) and execute complex tasks concurrently using Python threads.

## Core Architecture
Utilizes a dynamic persona-prompt injection engine coupled with parallel execution (`ThreadPoolExecutor`) to emulate an AI swarm without the architectural bloat of heavy microservice frameworks.

## Tech Stack
* **Brain:** Google AI Studio (`gemini-3.6-flash`)
* **Language:** Python 3.10+
* **Interface:** Streamlit Community Cloud
* **Version Control:** GitHub
